# RevConnect

## Application Overview

RevConnect is a console-based social media application developed using Java, MySQL, and JDBC. The platform enables personal users, businesses, and content creators to connect, interact, and share content through posts, likes, comments, follows, and notifications.

The application follows a modular layered architecture and is designed to be scalable for future web or microservices-based expansion.

---

# Features

## Authentication & Profile Management

- User Registration and Login
- Secure Authentication using Email and Password
- Edit and Manage User Profiles
- View Own and Other User Profiles
- Search Users by Username or Name
- Change Password Functionality
- Privacy Settings Support

---

## Post Management

- Create Text Posts with Hashtags
- Edit and Delete Posts
- Personalized Feed
- View Posts from Connections and Followed Accounts
- Share/Repost Content
- Trending Hashtag Support

---

## Social Interaction Features

- Like and Unlike Posts
- Add and Delete Comments
- Follow and Unfollow Users
